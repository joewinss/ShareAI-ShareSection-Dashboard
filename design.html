Gradients

Two gradient directions used across buttons, footers, and accent elements. Always Green → Blue, left to right.

theme-gradient-button
gradient-accent
/* Primary gradient — Buttons, footer CTAs */ .theme-gradient-button { background: linear-gradient(90deg, #16a34a 0%, #2563eb 100%); } /* Accent gradient — Mobile footer, overwrite.css */ background: linear-gradient(to right, #22c55e, #3b82f6);
Note: The gradient direction varies slightly between usages (90deg vs to right) but the color stops are consistent. Prefer to right for new code.

Inputs

Form inputs use Shadcn's input.jsx base and Ant Design's form components. Border: 214.3 31.8% 91.4%. Focus ring: green-500 with opacity 15% glow.

// input.jsx "flex h-8 w-full rounded-md border border-input bg-background px-3 py-1 text-sm shadow-sm transition-colors file:border-0 file:bg-transparent focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-ring disabled:cursor-not-allowed disabled:opacity-50"

Libraries & Stack

LibraryVersion / NotesUsed For
Tailwind CSS core Utility classes, spacing, colors, responsive
Ant Design v5 Tables, Modals, Drawers, Forms, message toasts
Radix UI shadcn Dialog, Tabs, Select, Switch, DropdownMenu, AlertDialog
CVA class-variance-authority Button, Badge, Input variant management
Lucide React icons All iconography
Framer Motion animation Sidebar submenu expand/collapse, transitions
Recharts charts LineChart, BarChart, PieChart on analytics pages
clsx + tailwind-merge utils cn() utility — all component composition
Layering rule: Radix/Shadcn for interactive primitives that need accessibility. Ant Design for complex data-heavy components (tables, drawers, forms). Never mix both for the same component type.

Conventions & Rules

Repeated Patterns to Follow
PatternRule
Image thumbnails Height 144px, object-fit: cover, border-radius: 8px, hover blur with Ant Design PreviewGroup
Table pages Ant Design Table + FilterDrawerV2 + FilterTags + ExportModal + pagination
Date display Always format as DD MMM YYYY (e.g. 11 May 2026)
Toast notifications Ant Design message.* for in-app toasts; Shadcn toast for persistent
Gradient buttons Use .theme-gradient-button class for all primary CTAs
Destructive actions Always red-600 (#dc2626), never red-500 alone, confirm dialog required
Active nav state text-green-600 bg-green-50 border-r-2 border-green-600
Page section gap space-y-6 (24px) for stacked sections
Credit balance refresh Use useRefreshCreditBalance() — never write to store directly
Role checks Always via user?.user?.role from Redux, not localStorage directly
Number decimals Use numberDecimal = 2 from startUp.js — never hardcode
Timezone "Asia/Kuala_Lumpur" from startUp.js — never hardcode
Class Utility Pattern
// Always compose classes with cn() from /lib/utils import { cn } from "@/lib/utils" <div className={cn( "base-classes", isActive && "active-classes", className // always forward className prop )} />
Drawer Pattern (Ant Design)
// Standard drawer padding variants .ant-drawer-body { padding: 12px; } /* default */ .ant-drawer-body.no-padding { padding: 0; } /* image/media drawers */
