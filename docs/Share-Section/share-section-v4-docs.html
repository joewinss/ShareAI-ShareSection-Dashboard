04 — Share Logic

executeShare Decision Tree

Platform type routing, Web Share API detection, image file prep, and fallback handling — all returning a typed result status.

shared fallback_download text_only_fallback images_not_ready cancelled failed 
handlePlatformShare(platformType, platformTitle, text, imageUrls, platformUrl)
│
├─ isFilesOnlySharePlatform(platformTitle)?   // rednote | tiktok | lemon | yelp
│  └─ YES → executeShare(filesOnly, includeText=false, skipCopy=autoCopyText)
│
├─ platformType === 'OTHER'?
│  └─ YES → executeShare(text + images via native share)
│
├─ platformType === 'URL'?
│  └─ YES → copyText() → window.open(platformUrl) → { status:'shared', mode:'url' }
│
└─ (no match) → { status:'failed', reason:'unsupported_platform_type' }


executeShare(text, imageUrls, skipCopy, preparedImageFiles, ...)
│
├─ !skipCopy?  → navigator.clipboard.writeText(text)
│
├─ hasImages && cachedFiles.length === 0?   // proxy-image fetch still in-flight
│  └─ YES → { status:'images_not_ready' }
│
├─ !navigator.share?   // Web Share API not available
│  ├─ hasImages → /api/download-image fallback → { status:'fallback_download' }
│  └─ !hasImages → { status:'text_only_fallback' }
│
├─ canShareFiles && cachedFiles.length > 0?   // navigator.canShare({ files })
│  └─ navigator.share({ files, text? })
│     ├─ success  → { status:'shared', mode:'files' }
│     ├─ AbortError → { status:'cancelled' }
│     └─ other error → { status:'failed' }
│
├─ hasImages && !canShareFiles?
│  ├─ !allowTextOnlyNativeShare → download fallback → { status:'fallback_download' }
│  └─ allowTextOnly → fall through to text share ↓
│
└─ navigator.share({ text })
   ├─ success  → { status:'shared', mode:'text' }
   ├─ AbortError → { status:'cancelled' }
   └─ other error → { status:'failed' }


// Post-share: if status==='shared' AND platform !== OTHERS AND mode !== 'url'

05 — Modal States

5 Modal Types

All powered by SinglePopUpModal with a type prop. Each has its own open/close state and callback chain.

guidedShareFlow
6-step wizard
Main share flow modal. closeable=false. Driven by guidedStepIndex and guidedSteps[] array. Auto-opens once platforms load.
guidedReplayFinal
replay flow
Shown after first successful share. Lets user share again without re-selecting platform. closeable=false → close ends session.
successfulShare
success
Two actions: End session (redirect to itscreative.biz/ishare) or continue to replay flow. Hidden while waitingForApp is true.
contentNotFound
guard
Shown when language/category/content is unavailable. closeable=false. Only action is to end the session.
connectionIssue
error
Shown when waitForAppOpen times out (10s) without detecting a blur/hidden event. User can dismiss and retry.
