02 — Dynamic Step Flow

4-Step Wizard

Steps are computed at runtime from the normalised field list — only steps that have at least one field appear. The Generate step always appears last and maps to the isMerging review state.

Image (conditional step)
Only present when requiredUI contains an image-upload or image-select field. Renders the Image Reference Source card with watermark 01. This step is always optional — "Continue" is never disabled here.
inputType === 'image-upload' → step 1 inputType === 'image-select' → step 1

rendered by: ImageUploadRenderer | ImageSelectRenderer

Settings
Required fields — pill selects and text inputs that must be filled before the user can advance. Renders the Settings card with watermark 02. "Continue" is disabled until isStep2Complete is true.
CHOICE_TYPE fields with options.length → must have value TEXT_LIKE fields (required !== false) → must be non-empty

isStep2Complete also returns false while isFetching is true

Optional Details (conditional step)
Only present when any field in requiredUI has required === false or is a TEXT_LIKE type without an explicit required: true. Renders the Optional Details card with watermark 03.
required === false → step 3 TEXT_LIKE + no explicit required → step 3

"Review & Generate" button: disabled when !canGenerate

Generate
Not a traditional form step — clicking it calls goStep(totalSteps) which sets isMerging = true. The right panel expands full-width showing the image preview, all field values, and the main Generate Visual Series CTA.

handleGenerate() → await onGenerate() → sets hasGenerated=true

result !== false → hasGenerated = true canGenerate = false → button disabled

03 — Input Renderers

8 Renderer Types

Exported from visualInputRenderers.jsx and mapped in INPUT_RENDERERS. VisualDynamicInputV2 calls renderField(entry), which picks the correct renderer by entry.inputType. Unknown types fall back to UnsupportedFieldRenderer.

image-upload
ImageUploadRenderer
Renders ImageUploadWithPreview with a counter. Reads selectedImages, imagePreviews, maxRequiredImages, and minRequiredImages from context. Always assigned to step 1.
image-select
ImageSelectRenderer
Grid of previously-generated visuals fetched from getGeneratedVisualContent by industryCode. Selected URLs are converted to File objects via convertGeneratedImageUrlsToFiles. A Refresh button re-queries the API.
image-grid-square
ImageGridRenderer
Renders SelectionGrid in square aspect ratio. Supports modelPreview config to overlay assembled model images (race × gender × age × hair) from public/assets.
image-grid-portrait
ImageGridRenderer
Same as above but SelectionGrid uses portrait aspect ratio. Used for modes where tall imagery is more natural (e.g. model photos).
pill-select
PillSelectRenderer
Horizontal pill buttons. Options resolved from field.optionSource (e.g. styleOptions, angleOptions) or a static field.options array. Applies .vg-opt-pill CSS in visual-generator flow context.
text
TextRenderer
Wraps StringInput. Applies a 20-word limit via applyWordLimit() on every change. Falls back to TEXT_INPUT_FALLBACKS for label and placeholder when the field config omits them.
textarea
TextAreaRenderer
Ant Design Input.TextArea with 4 rows. Same 20-word cap as the text renderer. Used for longer freeform fields like about and description.
color
ColorRenderer
A native <input type="color"> swatch paired with an Ant Design text input for manual hex entry. Validates the hex pattern /^#[0-9A-Fa-f]{6}$/ before passing to the color swatch.

05 — State & Logic

Data Flow & Key Algorithms

How requiredUI[] becomes a rendered wizard — and how the canGenerate flag, field visibility, and the right panel stay in sync.

step 1 — image step 2 — settings step 3 — optional canGenerate = true canGenerate = false 
normalizeRequiredUI(requiredUI)
  // Accepts string[] | { key, label?, required?, options?, industryCode? }[]
  // Looks up each key in VISUAL_INPUT_FIELDS for inputType, label, placeholder, etc.
  // Sets entry.isUnknown = true and logs a console.warn for unrecognised keys
  → requiredEntries[]   (memoised on requiredUI)


visibleEntries = requiredEntries
  // Filter 1: hideWhen — if entry.hideWhen.key === hideWhen.value, entry is excluded
  .filter(entry ⇒ !(entry.hideWhen && fieldValues[entry.hideWhen.key] === entry.hideWhen.value))
  // Filter 2: dedup — entries with the same id appear only once
  .dedup(entry.id)


getFieldStep(entry)
  ├─ inputType === IMAGE_UPLOAD | IMAGE_SELECT  →  step 1
  ├─ entry.required === false                  →  step 3
  ├─ TEXT_LIKE + required === true             →  step 2
  └─ everything else (CHOICE_TYPES, etc.)      →  step 2


stepSequence (dynamic)
  if (imageFields.length)    push  { id: 'image',    label: 'Image' }
  if (requiredFields.length) push  { id: 'settings', label: 'Settings' }
  if (optionalFields.length) push  { id: 'optional', label: 'Optional' }
                             push  { id: 'generate', label: 'Generate' }  // always last


isStep2Complete
  ├─ isFetching → false
  ├─ CHOICE_TYPE field + options.length > 0 + no value → false
  ├─ TEXT_LIKE field + empty string → false
  └─ all pass → true

canGenerate
  isStep2Complete
  && !selectImagePreparing          // image-select URLs still being converted to Files
  && (imageFields.length === 0 || hasMinImages)   → canGenerate = true


modelPreviewUrl  (RightPanel)
  // Reads fieldValues.race, .gender, .age, .hair
  // Builds: Assets[`${race}_${g}_${a}_${h}`] from public/assets
  // Defaults: gender='F', age='21', hair='L' when a field is unset
  → image URL | null   (shown in RightPanel under "Model Preview")

stylePreviewUrl  (RightPanel)
  // Reads fieldValues.param, finds matching option in styleOptions[]
  → option.previewImage | null   (shown in RightPanel under "Style Preview")


navigateToField(key, step)
  // Fired when user clicks a value chip in RightPanel
  setIsMerging(false) → setActiveStep(step)
  setTimeout(80ms) → fieldRowRefs[key].scrollIntoView({ behavior:'smooth' })
                   → el.classList.add('shining')   // 1600ms highlight animation


preloadUrl effect
  // If preloadUrl prop is set AND selectImageUrls have loaded AND url is in the list:
  toggleSelectImageUrl(preloadUrl)   // auto-selects it
  appliedPreloadUrl.current = preloadUrl   // prevents re-application on re-render


// Reset effects
// When requiredUI changes (mode switch): all step state, selections, and generate flags reset
// When activeStep > totalSteps (dynamic step removal): clamped back to step 1
